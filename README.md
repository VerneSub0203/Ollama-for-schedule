PythonとOllama（`phi3`）を駆使し、認知負荷や圧倒感を防ぎながらタスクの分解や日々のスケジュール管理の壁打ち相手になってくれる、ターミナル完結型のスケジュールアシスタントです。

**主な特徴**

* **ローカルLLM連携:** Ollamaと軽量な小型言語モデル（`phi3`）を使用し、完全オフラインかつプライバシーを担保した環境で動作します。
* **対話型のタスク分解:** 圧倒的な量のテキストを一度に押し付けるのではなく、システムプロンプトによってAIが一度に1つずつ焦点を絞った質問をするよう強制されます。
* **永続的な対話ループ:** 動的なメッセージ履歴配列を使用し、セッション中の文脈を維持します。

**今後予定の追加機能**
* GoogleスケジュールへのAPIを介したスケジュール検索とAI読み込ませ
* GoogleスケジュールへのAPIを介したスケジュール追加
****

**動作環境（要件）**

* Python 3.x
* [Ollama](https://ollama.com/) がローカルにインストール・起動しており、`phi3` モデルがダウンロード済みであること（`ollama pull phi3`）
* Python用Ollamaライブラリ（`pip install ollama`）

**使い方**

```terminal
python Ollama-for-schedule.py

```
